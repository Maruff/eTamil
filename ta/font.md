## ican qamiz

இந்த எழுத்துருவில் ASCII எழுத்துகள் தமிழ் வரிவடிவங்களைச் சுமக்கின்றன. `c` ச-வை
வரைகிறது, `q` த-வை, `Z` ன-வை — ஒவ்வொரு எழுத்துக்கும் ஒரு வரிவடிவம், இ-தமிழ்
எழுத்துப்பெயர்ப்பின்படி. இதை நிறுவும் ஒருவர் சாதாரண விசைப்பலகையில் தமிழ் தட்டச்சு
செய்து, தமிழாகவே படிக்கிறார்; வட்டில் சேமிக்கப்படுவது ASCII-ஆகவே இருக்கும்.

## நிறுவுதல்

கோப்பைப் பதிவிறக்கி, வேறு எந்த எழுத்துருவையும் போலவே நிறுவுங்கள்: Windows-இல்
வலது-சொடுக்கி Install; macOS-இல் திறந்து Install Font; Linux-இல்
`~/.local/share/fonts`-க்கு நகலெடுத்து `fc-cache -f` இயக்குங்கள்.

[VS Code நீட்சி]({{ site.brand.vscode_url }}) இதே கோப்பைச் சுமந்து வருகிறது,
**eTamil: Install the eTamil font** மூலம் உங்களுக்காக நிறுவுகிறது; பிறகு
இ-தமிழாக உள்ள ASCII-ஐ இதில் வரையும், ஆங்கிலம் இலத்தீனாகவே இருக்கும்.

## இதில் இல்லாதவை

இந்த எழுத்துரு 129 குறியீட்டுப் புள்ளிகளை — அனைத்தும் ASCII மற்றும் Latin-1 —
வரைகிறது; தமிழ் தொகுதியின் ஒரு எழுத்தும் இதில் இல்லை. இது குறை அல்ல, வேண்டுமென்றே:
ASCII எழுத்துகளுக்குத் தமிழ் வடிவம் தருவதே இதன் நோக்கம், யுனிகோட் தமிழை திருத்தி
ஏற்கெனவே பயன்படுத்தும் எழுத்துருவே வரையும். எனவே திருத்தி தன் வழக்கமான
எழுத்துருவையே அடிப்படையாக வைத்து, இ-தமிழ் ASCII-ஐ மட்டும் இதில் வரைய வேண்டும் —
நீட்சி செய்வதும் அதுவே.

மேலும் எழுத்துருக்கள் — ஒரே அகலமுள்ள வடிவம், திருத்திக்கு அப்பாற்பட்ட
பயன்பாடுகளுக்கான எழுத்துருக்கள் — தயாரிப்பில் உள்ளன.
