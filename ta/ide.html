இது இ-தமிழ் தொகுப்பியே — WebAssembly-ஆகத் தொகுக்கப்பட்டு இப்பக்கத்திற்குள் இயங்குகிறது. நீங்கள் காணும் பிழைகள், கட்டளை வரியில் etamil காட்டும் அதே பிழைகள்; ஒரே குறியீட்டிலிருந்து வருகின்றன. எதுவும் பதிவேற்றப்படுவதில்லை, எதுவும் சேமிக்கப்படுவதில்லை — இப்பக்கத்தை மூடினால் அது போய்விடும்.

இங்கு என்ன இயங்கும்

மொழி மதிப்புகளுடன் செய்யும் அனைத்தும்: துல்லியமான தசமப் பணக் கணக்கு, சொற்கள், அணிகள், கட்டுப்பாட்டு ஓட்டம், செயல்கள், கணக்கியல் சொல்லகராதி. இயக்க Ctrl+Enter அழுத்துங்கள். கோப்பு கூற்றுகளும் இயங்கும் — ஒரு இயக்கத்தின் நேரம் மட்டும் நினைவில் நிலைக்கும் கோப்பு அமைப்பில்.

தனி இயந்திரம் தேவைப்படுபவை இங்கு இயங்காது, முயற்சிக்கும்போது அதைச் சொல்லும்: தரவுதளங்கள், Redis, HTTP சேவையகம், குறிதாங்கிகள், கடவுச்சொல் ஹாஷ், உள்ளிடு, ODF பொதிகள். அவற்றுக்கு தொகுப்பியை நிறுவுங்கள் — அது ஒரே கோப்பு, Rust-ம் C கருவித்தொகுப்பும் தேவையில்லை.

மொழி புதிதா? திறவுச்சொல் பட்டியல் விரைவான தொடக்கம்; மீதியை கையேடு விளக்கும்.
