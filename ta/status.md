இ-தமிழ் இன்று பின்தள நிரல்களை இயக்குகிறது: செயல்கள், தொகுப்புகள், பிழைக் கையாளுதல்,
தொகுதிகள், SQLite தரவுத்தள அடுக்கு, வழிச்செலுத்தலுடன் கூடிய ஒருங்கிணைந்த HTTP சேவையகம்,
மற்றும் இதே மொழியில் எழுதப்பட்ட கணக்கியல் கட்டமைப்பு.

இந்த அட்டவணை நிரலின் நேர்மையான நிலை; விருப்பப் பட்டியல் அல்ல.

| பரிவர்த்தனைகள், பல இணைப்புகள் | <span class="pill pill-no">செயல்படுத்தப்படவில்லை</span> | ஊகிப்பதற்குப் பதிலாக VM இரண்டாவது இணைப்பை மறுக்கிறது |
| நாணயத்துடன் கூடிய பண வகை | <span class="pill pill-no">செயல்படுத்தப்படவில்லை</span> | `எண்` மட்டுமே எண் வகை; எனவே ரூபாய் + எண்ணிக்கையைச் சரிபார்ப்பான் மறுக்க முடியாது |

</div>

*செயல்படுத்தப்படவில்லை* எனக் குறிக்கப்பட்ட எதுவும் அமைதியாக ஏதோ ஒன்றைச் செய்யாமல்
**தெளிவான பிழைச் செய்தியுடன் நிற்கிறது**. இது வேண்டுமென்றே: ஒரு வரிக் கணக்கீட்டில்
அமைதியான செயலின்மை, ஒரு பிழையை விட மோசமானது.

## திட்டமிடப்பட்ட துறைக் கட்டமைப்புகள்

நிதி அமைப்பின் மீதமுள்ள பகுதிகளுக்கு விரிவுபடுத்துகின்றன; ஒவ்வொன்றும் ஏற்கெனவே உள்ள

## தனித்தனியாக வைக்கப்பட்ட இரு எண்ணிடல் முறைகள்

இத்திட்டத்தில் தொடர்பற்ற இரு விஷயங்கள் "கட்டம் 1–N" என அழைக்கப்பட்டன. அவை முற்றிலும்
வேறுபட்டவை:

| சொல் | பொருள் |
|---|---|
| **கட்டுரைக் கட்டம் 1–5** | ஆய்வுத் திட்டவரைபடம்: தொகுப்பி மையம் → துறைத் தொகுதிகள் → கருவிகள்/REPL → முன்னோடித் திட்டங்கள் → கொள்கை ஈடுபாடு |
| **பின்தள மைல்கல் 1–4** | இக்களஞ்சியத்தின் HTTP வேலை: ஒத்திசைவு சேவையகம் → async → பதிவேடு → அங்கீகாரம் |

பின்தள மைல்கற்கள் 1–4 முடிந்திருப்பது, கட்டுரையின் கட்டம் 2 பற்றி எதுவும் கூறவில்லை;
அது தொடங்கவே இல்லை. **கட்டுரையின் முறைப்படி, இத்திட்டம் கட்டம் 1-இன் நடுவில்** உள்ளது:
தொகுப்பி மையம் உள்ளது, துறைத் தொகுதிகள் இல்லை.

உறுதியாகச் சொன்னால், [ஆய்வில்]({{ '/ta/research/' | relative_url }}) விவரிக்கப்பட்ட GSTN
மற்றும் NPCI API இணைப்புகள், ITR மற்றும் TDS வார்ப்புருக்கள், RBI/KYC தொடரியல்,
Hyperledger தணிக்கைத் தடம் ஆகியவை வடிவமைப்பு; நிரல் அல்ல.
