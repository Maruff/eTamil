This is the eTamil compiler itself, compiled to WebAssembly and running inside this page. The errors you see are the errors etamil prints on the command line, because they come from the same code. Nothing is uploaded and nothing is stored: close the tab and it is gone.

What works here

Everything the language does with values: exact decimal money, strings and arrays, control flow, functions, and the accounting vocabulary. Press Ctrl+Enter to run. File statements work too, against a filesystem that lives in memory for the length of one run.

What needs a machine of its own does not work here, and says so when you try it: databases, Redis, the HTTP server, tokens and password hashing, உள்ளிடு, and ODF packages. For those, install the compiler — it is a single binary and needs neither Rust nor a C toolchain.

New to the language? The keyword list is the fastest way in, and the manual covers the rest.
